# Maharashtra — Tech On Tour

Purpose:
Collect tourist places, hidden gems, lesser-known destinations, local experiences and tourism attractions from this region.

Instructions:

1. Find a real place.
2. Verify that the place exists.
3. Add it to places.csv.
4. Add accurate location information when available.
5. Add a source URL.
6. Explain why tourists should visit.
7. If it is a hidden gem, explain why.
8. Add your name in discovered_by.
9. Set verification_status to Pending.
10. Do not add fake information.

---

### Region Quick Details
- **Region Name**: `Maharashtra`
- **Region Type**: `State`
- **Directory**: `data/states/Maharashtra/`
- **Data File**: [`places.csv`](places.csv)

### Contribution Checklist for this Region
- [ ] Ensure `state_ut` is set to `Maharashtra`
- [ ] Provide district, city/town, and nearest major city
- [ ] Choose primary category from standard list (Nature, Heritage, Culture, Food, Adventure, etc.)
- [ ] Mark `hidden_gem` as `Yes` or `No`. If `Yes`, articulate the `hidden_gem_reason`
- [ ] Provide verifiable `source_url` and `source_type`
- [ ] Set `verification_status` to `Pending`
- [ ] Ensure NO fake or AI-hallucinated data is submitted
